## 核心收获

- 质量不是文档固有的单一分数；过滤阈值要随目标、算力和可用数据量选择。
- MinHash 估计相似度，LSH 寻找候选；概率筛选不能被误读成精确重复判定。
- 混合设计的关键账本是每源重复轮数，代理实验也必须模拟最终数据稀缺。

## 00:00:00–00:24:00｜有损转换与轻量过滤

HTML/PDF 抽取与目标分布过滤需要同时考虑质量、成本和训练预算。

### [00:00:00–00:04:00](https://www.youtube.com/watch?v=5sxHosTLPF8&t=0s)｜转换、过滤、去重、混合的流水线

- 原始网页、PDF 和仓库并非现成文本；HTML 抽取要决定正文、导航、广告、表格等哪些信息保留。
- 把层级或视觉布局压成 token 序列是有损过程，规则抽取虽快但有失败边界，不能把清洗当成无影响的预处理。

关键词：数据流水线 · HTML

### [00:04:00–00:08:00](https://www.youtube.com/watch?v=5sxHosTLPF8&t=240s)｜PDF 抽取与过滤问题的统一形式

- FinePDFs 例子展示截断 PDF 需重新获取，扫描件可能需 OCR/VLM；布局与语义结构缺失使处理比 HTML 更昂贵。
- 过滤可以抽象成：给少量目标数据 T 和大量原始数据 R，选择 R 中与目标分布相近的子集。

关键词：FinePDFs · 过滤

### [00:08:00–00:12:00](https://www.youtube.com/watch?v=5sxHosTLPF8&t=480s)｜低成本评分器如何外推质量

- 可在目标集训练 KenLM 等小生成模型，或以 T 为正例、R 样本为负例训练 fastText 分类器，再按分数选文档。
- 过滤器既要超出目标样本泛化，又要能扫描极大量 token；这解释了轻量模型与阈值筛选的常见组合。

关键词：KenLM · fastText

### [00:12:00–00:16:00](https://www.youtube.com/watch?v=5sxHosTLPF8&t=720s)｜语言、数学与教育价值过滤

- 语言识别可用现成模型，但混合语言和方言仍有边界；OpenWebMath 组合 LaTeX 规则、困惑度与分类器。
- GPT-3、LLaMA 和 phi-1 采用不同质量代理；phi-1 先让强模型判断教育价值，再以廉价模型推广到大量代码。

关键词：OpenWebMath · phi-1

### [00:16:00–00:20:00](https://www.youtube.com/watch?v=5sxHosTLPF8&t=960s)｜过滤阈值取决于训练预算

- 毒性过滤也可从标注评论训练分类器；关键是目标定义，不存在适合所有能力与用途的统一质量分数。
- 小数据池实验显示，高质量子集在初期高效，但反复训练会过拟合；训练 token 增加时，更宽的数据池可能更好。

关键词：毒性过滤 · 训练预算

### [00:20:00–00:24:00](https://www.youtube.com/watch?v=5sxHosTLPF8&t=1200s)｜过滤实验的统计与重复数据

- 课堂问答指出重复训练与置信区间值得做，但昂贵预训练常缺重复实验；不能把单次曲线当成没有不确定性。
- 过滤的总结是先定义好数据，再用便宜模型外推；接着引入镜像网站和 fork 导致的大量精确重复。

关键词：实验设计 · 重复

## 00:24:00–00:40:00｜去重问题与 MinHash

由精确哈希扩展到 Jaccard 和概率签名，避免直接进行全量两两比较。

### [00:24:00–00:28:00](https://www.youtube.com/watch?v=5sxHosTLPF8&t=1440s)｜去重的价值与设计维度

- 模板广告、公共许可和重复产品描述会浪费训练算力并加强记忆；去污染则专门防止测试内容进入训练集。
- 先决定句子、段落还是文档级去重，再决定精确/近似标准以及删全部还是保留一个，选择会影响文本完整性。

关键词：去重 · 去污染

### [00:28:00–00:32:00](https://www.youtube.com/watch?v=5sxHosTLPF8&t=1680s)｜哈希去重与相似度定义

- 精确去重可按哈希分组再保留代表，便于并行处理；C4 的三句片段去重可能把连贯文档切破。
- 近似去重不能直接对所有文档两两比较；用集合的 Jaccard 相似度，为后续高效候选检索定义目标。

关键词：哈希 · Jaccard

### [00:32:00–00:36:00](https://www.youtube.com/watch?v=5sxHosTLPF8&t=1920s)｜MinHash 的概率直觉

- J(A,B)=|A∩B|/|A∪B|；理想随机排列下，两个集合最先出现同一元素的概率恰为 Jaccard。
- MinHash 取集合元素哈希值的最小值；相似集合应更易碰撞，这与普通哈希尽量避免碰撞的目标不同。

关键词：MinHash

### [00:36:00–00:40:00](https://www.youtube.com/watch?v=5sxHosTLPF8&t=2160s)｜从单次碰撞到 LSH 分组

- 多次独立 MinHash 的匹配比例可估计相似度，但一次碰撞不能证明已超过某个近重复阈值。
- 将 n=b×r 个签名分为 b 个 band，每组 r 项：组内全部相同才匹配，任意一组匹配即可成为候选。

关键词：LSH · banding

## 00:40:00–00:48:00｜LSH 概率与参数选择

用 band 内 AND、band 间 OR 推导碰撞概率，并用 b、r 调整取舍。

### [00:40:00–00:44:00](https://www.youtube.com/watch?v=5sxHosTLPF8&t=2400s)｜推导 LSH 候选碰撞概率

- 设相似度 s，单组全部匹配概率 s^r；任一组匹配的概率为 1−(1−s^r)^b。
- 组内 AND、组间 OR 把线性碰撞概率改造成 S 形曲线，让高相似度对更易被检出，低相似度对更少出现。

关键词：LSH · 概率

### [00:44:00–00:48:00](https://www.youtube.com/watch?v=5sxHosTLPF8&t=2640s)｜调节 b、r 与成本

- 增大 r 会让匹配更严格、曲线向右；增大 b 给更多匹配机会、曲线向左，二者共同权衡误报与漏报。
- 约略转折点 s≈b^(−1/r)，仍不是硬阈值；增加签名数量能改善区分，却也增加计算和存储。

关键词：LSH · 阈值

## 00:48:00–01:00:00｜混合分布与重复轮数

均匀和比例混合都可能失效，需要显式约束小来源的重复使用。

### [00:48:00–00:52:00](https://www.youtube.com/watch?v=5sxHosTLPF8&t=2880s)｜跨来源去重与混合权重

- MinHash-LSH 适用于这里的 Jaccard 目标；去重应跨全部来源进行，否则分别干净的数据集合并仍会重复。
- 数据混合把来源转成概率分布；手工、均匀与按规模加权都是起点，不能默认哪种对所有任务最优。

关键词：跨来源去重 · data mixing

### [00:52:00–00:56:00](https://www.youtube.com/watch?v=5sxHosTLPF8&t=3120s)｜均匀混合可能暗中重复小数据集

- 假设低质量库 10T、高质量库 10B，训练 1T token 且各占一半：前者只用 5%，后者重复 50 轮。
- 因此混合权重不能只看质量，还必须看来源大小、多样性与训练长度；每源期望轮数为 p_s×T/N_s。

关键词：epoch · 混合预算

### [00:56:00–01:00:00](https://www.youtube.com/watch?v=5sxHosTLPF8&t=3360s)｜UniMax 给重复轮数设上限

- 问答解释通常按序列选择来源并在 batch 内混合，以减少波动；不是让每个 token 任意切换领域。
- UniMax 在均匀取样思路上限制每个来源的 epoch 数，防止低资源语言或小规模高质量库被过度重复。

关键词：UniMax · 采样

## 01:00:00–01:12:00｜回归混合与模拟重复

代理模型搜索应防优化分布外误差，并使小实验和大训练拥有相近的数据稀缺。

### [01:00:00–01:04:00](https://www.youtube.com/watch?v=5sxHosTLPF8&t=3600s)｜小模型回归预测最佳混合

- RegMix 类方法先训练一组小模型，改变混合比例，再拟合“权重→验证损失”，优化预测器后用于大模型。
- 需要选混合分布、回归模型与目标指标；如果评测偏代码，搜索自然偏向代码，可能牺牲未测的通用能力。

关键词：RegMix · 代理实验

### [01:04:00–01:08:00](https://www.youtube.com/watch?v=5sxHosTLPF8&t=3840s)｜混合搜索需要跨尺度迁移

- 预测器在普通采样点表现好，不保证在优化器挑出的极端权重仍准确；小模型最优也未必是大模型最优。
- 小实验尚未重复高质量数据，大实验却可能重复许多轮；可加 epoch 上限，或让小实验模拟大实验的数据稀缺。

关键词：跨尺度迁移 · 过拟合

### [01:08:00–01:12:00](https://www.youtube.com/watch?v=5sxHosTLPF8&t=4080s)｜Simulated epoching 及其边界

- 按小/大训练 token 比例缩小各来源，使小实验中的重复程度接近最终训练，避免错误偏好稀缺高质量数据。
- 例如 10B 对 1T 对应约 1/100 下采样；过小来源还会出现舍入和覆盖问题，需要检查实际访问次数。

关键词：simulated epoching

## 复习问题

1. 推导 1−(1−s^r)^b；增加 b 或 r 分别怎样影响误报、漏报和成本？
2. 给来源大小 N_s、混合权重 p_s 和总训练量 T，怎样计算并限制每源 epoch？
3. 为什么小规模最佳数据混合可能在大规模训练过拟合？模拟 epoch 怎样修正？

## 易错点

- LSH 返回近似候选，不保证每个碰撞对都超过设定相似度；近线性可扩展性也不消除大桶等实现成本。
- 过滤分数高不意味着无限重复也好，混合权重必须联合来源大小与训练 token 预算。
- 不能用单个教师能力榜推断蒸馏效果，也不能把多回答样本数当成独立任务数。
