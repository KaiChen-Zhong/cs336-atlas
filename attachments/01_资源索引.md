## 8. 第一轮快速学习：完成哪些具体动作

以下是学习建议，不是官方课程时长承诺。

1. **建主线**：打开 L01、L02、L03 与 A1 题面；画出文本 → token → Transformer → loss → optimizer → checkpoint。
2. **跑通最小闭环**：通过 A1 基础测试，在小样本上观察 loss 下降，解码几段输出；出现异常再回看对应片段。
3. **解释成本**：用 L05–L08/A2 找一次真实瓶颈，记录输入形状、dtype、硬件、正确性误差、耗时与显存。
4. **学会做实验**：L09–L14 配 A3/A4；固定模型与预算，改变一个变量，比较验证损失与处理后的样本。
5. **理解后训练**：L15–L17 配 A5；分清 SFT 数据、偏好信号、可验证奖励和策略更新。
6. **按缺口补充**：只有公式、实现或实验结果卡住时，再打开工具文档、中文辅助与论文。资源索引负责定位，逐视频笔记负责回放与复习。
