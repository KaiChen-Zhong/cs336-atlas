从 CLIP、SigLIP 的图文表示学习，逐步拼接出 LLaVA 和 Qwen 视觉语言模型，再以 Chameleon 对照连续输入与离散生成的取舍。

## 核心收获

- 视觉编码器、投影器和语言模型组成常见 VLM；输入图像不等于模型能输出图像。
- 分辨率、视觉 token 数、时空位置与数据混合权重共同决定多模态任务效果和成本。
- 理解与生成对信息粒度要求不同，统一离散接口虽简洁，却带来细节损失与混合训练稳定性问题。

## 00:00:00–00:20:00｜多模态接口与 CLIP

将图像转换为语义表示，以图文对比目标获得零样本分类能力。

### [00:00:00–00:04:00](https://www.youtube.com/watch?v=26FtD08ZpOU&t=0s)｜多模态模型首先需要表示接口

- 本讲从纯文本模型转向图像、音频与视频，目标是理解任意模态组合的输入输出；实际内容主要聚焦图像如何进入语言模型。
- Transformer 接收的是 token 表示，既可离散也可连续；非文本数据需要合适编码方式，单个像素通常不像子词那样包含可直接利用的语义。

关键词：多模态 · token

### [00:04:00–00:08:00](https://www.youtube.com/watch?v=26FtD08ZpOU&t=240s)｜CLIP：对齐图像与文字

- CLIP 用网络上的图文配对代替只依赖人工类别标签：分别编码图像与文本，再让匹配组合的相似度高于同批次的不匹配组合。
- 一批 N 对样本形成 N×N 相似度矩阵，对行、列分别做分类，构成双向对比目标；归一化表示与温度参数控制比较尺度。

关键词：CLIP · 对比学习

### [00:08:00–00:12:00](https://www.youtube.com/watch?v=26FtD08ZpOU&t=480s)｜图文数据与固定分辨率的代价

- 原始 CLIP 使用约四亿图文对但未公开该数据集；OpenCLIP 借助公开数据复现和扩展，LAION 的筛选又利用已有 CLIP，形成自举关系。
- 调整短边再中心裁剪，能把任意尺寸图像变成固定输入，却会丢掉边缘或细节；这类设计与当时以图像分类为主的目标密切相关。

关键词：OpenCLIP · 图像预处理

### [00:12:00–00:16:00](https://www.youtube.com/watch?v=26FtD08ZpOU&t=720s)｜视觉 Transformer 与语义监督

- 图像增强可以把同一对象的不同外观联系起来，文本配对则提供更高层语义联系；两类监督并不保证学习到完全相同的表示。
- ViT 把图像切成小块、投影为向量并加入位置信息，再输入 Transformer；ViT-L/14 中的 14 指 14×14 像素块，而非整张图像尺寸。

关键词：ViT · patch

### [00:16:00–00:20:00](https://www.youtube.com/watch?v=26FtD08ZpOU&t=960s)｜文本编码与零样本分类

- CLIP 文本编码器用序列末尾 EOS 的高层表示汇总文字；预测类别时，将图像向量与候选类别的文本表示比较，无需另训该任务的分类头。
- 图文对和批内负例都带噪声：不同文字可能描述同类对象，网页文字也未必直述图像；规模与过滤帮助学习，但不会自动消除这些问题。

关键词：零样本分类 · EOS

## 00:20:00–00:32:00｜SigLIP 与可扩展的图文对齐

用成对二分类改善批次耦合与分布式计算，并转向视觉指令数据。

### [00:20:00–00:24:00](https://www.youtube.com/watch?v=26FtD08ZpOU&t=1200s)｜从 CLIP 的限制到 SigLIP

- CLIP 的早期结果说明，学习适合分类的语义表示未必需要逐词生成完整描述；该结论受评估目标限制，不能外推为生成训练始终无用。
- SigLIP 把批内匹配问题改成图文对的二分类：对角线为正例、非对角线为负例，用 sigmoid 损失替代跨整批 softmax 归一化。

关键词：SigLIP · sigmoid

### [00:24:00–00:28:00](https://www.youtube.com/watch?v=26FtD08ZpOU&t=1440s)｜SigLIP 如何分块计算

- 每张设备先计算本地图文组合，再交换文本表示，逐步覆盖跨设备负例；按图文对计算损失，使通信和计算更容易拆成块。
- WebLI 还利用 OCR 形成监督并支持多语言；课堂强调 SigLIP 的训练效率与较小批次表现，硬件代际不能仅凭名称直接换算速度。

关键词：SigLIP · 分布式

### [00:28:00–00:32:00](https://www.youtube.com/watch?v=26FtD08ZpOU&t=1680s)｜批次规模与 LLaVA 的训练数据

- SigLIP 减少了目标对整批 softmax 的依赖，小批次主要影响采样与估计质量；继续增大批次也会遇到收益减弱，不能无限换取性能。
- LLaVA 用 COCO 的人工说明和目标信息提示 GPT-4，合成问答、详细描述与推理对话，再与原图配对；这是构造视觉指令数据的一条路线。

关键词：LLaVA · 合成数据

## 00:32:00–00:48:00｜LLaVA：拼接模型与高分辨率扩展

通过适配器连接预训练模型，利用分块、任务数据和组合迁移扩展输入类型。

### [00:32:00–00:36:00](https://www.youtube.com/watch?v=26FtD08ZpOU&t=1920s)｜LLaVA 的投影器与两阶段训练

- CLIP 视觉特征经过投影矩阵 W，映射到语言模型能接收的向量空间，再与文本表示拼接；图像特征不必先变成真实文字词元。
- 第一阶段冻结视觉编码器和语言模型，只训练 W；第二阶段继续冻结视觉编码器，联合微调 W 与语言模型，使其学习图像条件下的指令回答。

关键词：LLaVA · 投影器

### [00:36:00–00:40:00](https://www.youtube.com/watch?v=26FtD08ZpOU&t=2160s)｜OneVision 与高分辨率输入

- LLaVA-OneVision 仍采用视觉编码器、投影器和语言模型的组合，替换为 SigLIP、两层 MLP 与 Qwen2，并扩展到多图和视频。
- AnyRes 把高分辨率图像分块编码，同时保留整体视图，避免简单缩小后读不清文字；块数增加也会扩大视觉序列，需要压缩与预算控制。

关键词：LLaVA-OneVision · AnyRes

### [00:40:00–00:44:00](https://www.youtube.com/watch?v=26FtD08ZpOU&t=2400s)｜为单图、多图与视频分配 token

- 单图可分配更细局部视图，多图使用较基础分辨率，视频进一步减少每帧 token；这种区别用于控制上下文开销和重复帧的训练占比。
- 训练数据大量针对视觉问答、表格、图像差异等任务构造，并分阶段从对齐走向更具体的能力；数据策划是这套模型的重要工作。

关键词：视觉 token · 数据混合

### [00:44:00–00:48:00](https://www.youtube.com/watch?v=26FtD08ZpOU&t=2640s)｜跨输入形式迁移与 Qwen-VL

- 单图中的 OCR、图表理解或圈选提示，能在某些实验中迁移到多图、视频和界面任务；这些例子展示组合泛化，但不保证所有未见组合都有效。
- 早期 Qwen-VL 用 OpenCLIP 视觉编码器与带二维位置的交叉注意力适配器，压缩到固定长度；首阶段冻结语言模型，训练视觉部分及适配器。

关键词：迁移 · Qwen-VL

## 00:48:00–01:00:00｜Qwen-VL：动态分辨率、时空结构与融合

沿 Qwen 系列比较位置编码、长上下文、跨层视觉信息及训练阶段。

### [00:48:00–00:52:00](https://www.youtube.com/watch?v=26FtD08ZpOU&t=2880s)｜Qwen2-VL 的动态分辨率与 MRoPE

- Qwen-VL 后续阶段使用更高质量任务数据和指令数据；Qwen2-VL 则进一步按输入分辨率分配视觉 token，并合并相邻块减少序列长度。
- MRoPE 把位置分为时间、高度、宽度三个轴，将一维旋转位置编码扩展到图像和视频结构，使相对位置关系不只依赖展平后的序号。

关键词：Qwen2-VL · MRoPE

### [00:52:00–00:56:00](https://www.youtube.com/watch?v=26FtD08ZpOU&t=3120s)｜Qwen3-VL 的时空位置改进

- Qwen3-VL 延续同类架构，强化长上下文理解并使用 SigLIP2；交错分配 MRoPE 的时、宽、高维度，让各轴都覆盖不同频率范围。
- 显式视频时间戳作为额外 token 进入输入，使时间不仅隐含在位置编码中，也能被文字问题直接指向，有助于描述特定时刻的事件。

关键词：Qwen3-VL · 视频时间戳

### [00:56:00–01:00:00](https://www.youtube.com/watch?v=26FtD08ZpOU&t=3360s)｜跨层视觉融合与分阶段训练

- DeepStack 将不同层的视觉特征注入语言模型多个层级，相比只在输入端接入一串视觉向量，提供更多层次的图像信息。
- 训练逐步扩展到 8K、32K、256K 上下文，再进行长推理 SFT、蒸馏与 RL；长度加权用于平衡长视频与短样本，课堂未完整展开其精确公式。

关键词：DeepStack · 长上下文

## 01:00:00–01:08:00｜能力边界与多模态系统

澄清输出形式、数据加载成本与公开数据配方对复现的影响。

### [01:00:00–01:04:00](https://www.youtube.com/watch?v=26FtD08ZpOU&t=3600s)｜这些 VLM 输出什么，系统难在哪里

- 本讲的 LLaVA、Qwen-VL 路线主要把图像或视频作为输入，输出仍是文字；大部分监督阶段按目标 token 训练，不能据此称其会生成视频。
- 多模态数据体积大，读取与解码可能成为瓶颈，需要与计算异步重叠；视觉序列更长也要求控制样本混合权重，而非只增加设备计算量。

关键词：VLM · 数据加载

### [01:04:00–01:08:00](https://www.youtube.com/watch?v=26FtD08ZpOU&t=3840s)｜复现边界与统一生成的另一条路

- 视觉编码器和适配器通常小于语言模型，但这不能简单解释成视觉部分只处理独立局部块；整体能力依赖视觉表示与语言推理的配合。
- 后期模型的完整数据配方并不总公开；接下来 Chameleon 尝试把图像也变成离散 token，使同一个自回归模型既理解又生成图文序列。

关键词：复现 · Chameleon

## 01:08:00–01:17:40｜Chameleon：统一离散生成的收益与代价

由图像码本解释统一自回归建模，并检查细节损失、稳定性和任务粒度。

### [01:08:00–01:12:00](https://www.youtube.com/watch?v=26FtD08ZpOU&t=4080s)｜VQ-VAE 如何得到图像 token

- VQ-VAE 先产生连续表示，再选最近码本向量得到离散编码，解码器从这些编码重建图像；训练还需处理量化不可微的问题。
- Chameleon 将 512×512 图像表示为 1,024 个视觉 token，码本大小 8,192，再与文本共同建模；统一 token 接口允许文字与图像交错生成。

关键词：VQ-VAE · 码本

### [01:12:00–01:16:00](https://www.youtube.com/watch?v=26FtD08ZpOU&t=4320s)｜统一离散表示的稳定性与信息损失

- 图像和文本 token 的预测难度及分布不同，统一编号并不会消除模态差异；Chameleon 用 QK normalization、z-loss 等控制训练中的数值增长。
- 离散压缩可能损失 OCR 所需的微小细节，模态混合也更难稳定；其接口简洁应与实际表现、细节保留和训练成本一起评价。

关键词：Chameleon · 训练稳定性

### [01:16:00–01:17:40](https://www.youtube.com/watch?v=26FtD08ZpOU&t=4560s)｜理解与生成需要不同粒度

- 分类重视高层语义，OCR 和图像生成则需要更细信息；没有一种编码压缩比例可以不加区分地同时满足所有任务。
- 课程以连续编码器、Transformer 与生成方法的组合结束，并提醒平衡视频和文本的权重；闭源模型具体结构的推测不构成已公开事实。

关键词：多模态 · 信息粒度

## 复习问题

1. CLIP 与 SigLIP 的损失分别怎样使用批内负例？这对批次大小和多设备实现有什么影响？
2. 若文档 OCR 表现差，应怎样检查裁剪、分辨率、视觉 token 压缩及位置编码？
3. LLaVA 类连续视觉输入与 Chameleon 离散图像 token，在输出形式、信息损失和训练稳定性上有什么差异？

## 易错点

- 把投影后的连续视觉向量说成已经识别出的文字 token，或把 VLM 文字回答误称为图像生成。
- 将课堂围绕分类的 CLIP 结论外推到 OCR、定位、图像生成等所有视觉任务。
- 根据单项性能表、参数大小或统一 token 接口，推断完整模型的数据配方、推理机制和普遍泛化能力。
