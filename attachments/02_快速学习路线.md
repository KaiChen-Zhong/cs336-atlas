# CS336 Spring 2026：快速学习路线

这里是学习建议；视频逐段摘要见独立的“逐讲笔记”目录。先用问题定位，再看相关时间窗，最后动手验证。默认你会 Python，接触过反向传播；若没有，从资源索引的 PyTorch Basics 与 micrograd 补起。

## 1. 三种投入方式

| 路线 | 怎么用这份资料 | 完成标准 |
|---|---|---|
| 先建立全局地图 | 按顺序读 18 份笔记的主线与核心收获；打不开的概念再看对应 4 分钟视频窗 | 能解释一条文本如何变成可部署模型，以及每阶段消耗什么资源 |
| 先做出最小模型 | 精学 L01–L03，完成 A1 的小样本训练闭环；按失败点回查 L02 的数值、形状和资源核算 | 能自己从 token 输入走到 loss、更新、保存、生成；解释每个张量的形状 |
| 系统掌握整门课 | 依照下表过完全部讲次；五个作业先做正确性与小规模实验，再按需要扩大规模 | 每个模块留下代码、实验记录、结论与失败分析 |

18 个公开视频合计 **24 小时 9 分 56 秒**。纯播放按 1.5 倍速约 16 小时 7 分，按 2 倍速约 12 小时 5 分；不含暂停、复习与作业时间。公式推导和代码演示适合降速。不要用“看完”替代掌握。

## 2. 六个学习阶段

| 阶段 | 视频 | 先带着哪个问题看 | 最小练习或可检查成果 | 对应作业 |
|---|---|---|---|---|
| 1. 建模闭环 | L01–L03 | 文本如何被编码？模型怎样算下一个 token 的概率？梯度更新什么？ | 手算一次 BPE 合并；标注 Transformer 各层形状；验证小样本 loss 下降 | A1 |
| 2. 架构选择 | L04 | Attention、有限状态模型与 MoE 分别改变哪种计算或内存成本？ | 同一上下文长度下，比较三类架构的状态增长与信息访问能力 | A1 理解扩展 |
| 3. 系统效率 | L05–L08 | 慢在算术、访存、调度还是跨卡通信？ | 记录一次正确的 GPU benchmark；画出 DDP/TP/PP/FSDP 的数据与通信位置 | A2 |
| 4. 预算与推理 | L09、L10、L11 | 固定预算怎样选模型与数据？训练最优与部署最优为何可能不同？ | 用小表拟合损失趋势；分别估计 prefill 与 decode 的计算/访存成本 | A3；连接 A2 |
| 5. 测量与数据 | L12–L14 | 分数可信度怎样判断？哪些文本值得训练，怎样验证过滤有效？ | 固定模型和预算做一次数据消融；检查样本、去重与验证集污染 | A4 |

## 3. 每讲只做这四步

1. **先读大段主线**：确认本讲解决的问题、前置概念与最终结论。
2. **按小段回放**：每个 4 分钟窗有时间链接；只针对不熟的推导、示例和问答回看。时间窗是检索单位，不是官方章节边界，话题可能横跨相邻两窗。
3. **合上笔记复述**：回答该讲的三个复习问题；说不清的术语、条件或成本再回看。
4. **留一份证据**：公式手算、形状图、小测试、计时结果或数据样本，任选与本讲相符的一项。

## 4. 常见卡点 → 回哪里

| 卡点 | 首看 |
|---|---|
| 分词器无法还原原文、特殊 token 处理混乱 | L01；A1 tokenizer 题面与测试 |
| reshape、broadcast、einsum 看不懂 | L02；einops 官方教程 |
| loss 变成 NaN，不知从哪查 | L02 数值精度；L03 归一化、初始化、学习率；A1 对应测试 |
| 算不清训练显存、参数量或 FLOPs | L02；L03；需要分片时看 L08 |
| GPU 占用低，优化没效果 | L05 硬件层级；L06 计时与 kernel；跨卡任务再看 L07–L08 |
| 分不清 ZeRO、FSDP、DDP、TP、PP | L07 实作建立通信图；L08 比较状态切分与成本 |
| 训练越大越好，但预算如何分配不清楚 | L09、L11；A3 的小规模实验路径 |
| 服务吞吐提高，单请求却更慢 | L10；Dan Fu 嘉宾课，检查 batch、KV cache、调度与延迟约束 |
| 模型分数上升，不确定是否真的变好 | L12；L14 去重/污染；固定评测协议与随机性 |
| RLHF、DPO、GRPO、RLVR 混成一团 | L15–L17；区分数据来源、奖励类型、优化目标 |

## 5. 每次实验最低记录项

记录 **代码版本、数据版本/切分、随机种子、模型配置、dtype、硬件、训练 token/步数、耗时、峰值显存、验证指标、生成样本**。一次先改一个可解释的因素。

资源先读 P0；P1 只补当前缺口；P2 用作另一种解释。论文先看与当前问题相关的图、方法和实验，再决定是否全文精读。
